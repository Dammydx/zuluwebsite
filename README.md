# Zulu Website – Frontend

This is the **frontend-only** implementation of the **Zulu Website**, built with a modern React ecosystem and structured for performance, clean UI/UX, and easy deployment.

## 🚀 Tech Stack
- **Next.js 14** – App Router & optimized routing  
- **React** – Component-based UI  
- **TypeScript** – Strong typing for safer development  
- **TailwindCSS / Custom UI/UX** – Clean, responsive interface  
- **Paystack Integration** – Secure online payments  
- **Vercel** – Hosting & continuous deployment

## 🎨 Features
- Fully responsive user interface  
- Smooth and modern UI/UX  
- Multi-step brand/vendor onboarding flow  
- Clean navigation & page structure  
- Payment integration with Paystack  
- Fast Vercel deployment pipeline  
- Frontend only (no backend included)
